# Implementation Log: Task 15

**Summary:** Resize rule for text in SelectionTransforms: a selection with a point text always scales uniformly (HasPointText, used by Resize, SetSize and the snapping of the drag), and ScaleAbout and the single-shape SetSize path scale a point text's FontSize and LetterSpacing by the box factor, clamped to the text limits; an area text only changes its box. Groups work because the drag transforms the leaves. CanvasInteraction.FitPointTexts re-measures point texts after each resize step and keeps their centers, so the box follows the measured size. Typed width/height in the Properties panel scale the font but are not re-measured (the box is the scaled one, exact again after the next edit). 15 tests.
