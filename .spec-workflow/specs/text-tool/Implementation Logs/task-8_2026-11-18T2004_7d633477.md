# Implementation Log: Task 8

**Summary:** Spike result: Avalonia 12 has no public API to read geometry contours (BuildGeometry gives a GeometryGroup of an opaque PlatformGeometry, distance sampling reaches only the first contour, HarfBuzzSharp 8.3.1.3 has no draw API). With the owner's approval SkiaSharp (already in Directory.Packages.props, shipped with Avalonia.Skia) is now a direct App dependency (SkiaSharp.NativeAssets.Linux added to App.Tests). AvaloniaTextOutliner takes the glyph ids, advances and baselines Avalonia shaped (same layout as the canvas via the new shared AvaloniaTextLayouts), reads each glyph's path with SKFont.GetGlyphPath from a copy of the font file, and GlyphOutlines converts the Skia path to DocumentSubPaths (quads to cubics, conics cut into quads, closing point merged). Verified against Avalonia's own text geometry: contour bounds identical for regular text and for bold italic (synthetic oblique skew -0.3). Also added TextFonts: the default font name Inter maps to the bundled fonts:Inter#Inter (the plain name falls back to Noto Sans), to be used by drawing and the editor too. Limits: TTC fonts read as first face, overlapping contours not merged.
