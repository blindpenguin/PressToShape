# Implementation Log: Task 16

**Summary:** Added the three node drags (new partial CanvasInteraction.NodeDrags.cs, small hooks in CanvasInteraction.cs for moves, release, step types and Abort): MovingNodes (selected nodes move together with their handles, Shift limits to one axis), MovingHandle (type rules, Alt breaks the link, a handle within 2 px of its anchor is removed, the grab offset is kept) and Bending (Node tool only; a press on a segment also selects its two end nodes). Every move is computed from the start state and previewed; the release records one step (MovePathPoints, MovePathHandle, BendSegment); a rectangle or ellipse is converted in the first changed preview, so conversion and edit are one step and a click without a move converts nothing. A Shift-click only changes the selection. Abort restores the start document. NodeEditor now exposes NodeTarget, Targets and IsSame for reuse. 31 new tests; one task-15 test used a point that is now a segment hit with the Node tool and was moved to Direct Select.
