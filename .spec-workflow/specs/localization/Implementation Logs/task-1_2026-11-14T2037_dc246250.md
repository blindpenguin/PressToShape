### Integrations

#### Integration
- **Description:** Translation build chain: Translations/*.po -> msgfmt --check -> obj/<config>/<tfm>/translations/<code>.mo -> EmbeddedResource with LogicalName PressToShape.App.Translations.<code>.mo. Load with GetText.Catalog(Stream, CultureInfo): GetString(text), GetParticularString(context, text), TranslationExists(text). Lessons: (1) the EmbeddedResource needs WithCulture=false and a qualified item metadata reference (%(_TranslationMo.Filename)), otherwise the file name de.mo is taken as a culture and the resource gets a wrong name. (2) msgfmt prints warnings unless the .po header has Language-Team, Last-Translator and PO-Revision-Date. (3) To test a missing tool via PATH, dotnet is symlinked in /usr/bin next to msgfmt, so run /usr/share/dotnet/dotnet directly with a PATH that excludes /usr/bin, and use -nodeReuse:false plus dotnet build-server shutdown because MSBuild nodes keep the old environment.
- **Frontend Component:** PressToShape.App.csproj
- **Backend Endpoint:** GetText.NET / msgfmt
- **Data Flow:** build time compile and embed, runtime load from assembly resources
