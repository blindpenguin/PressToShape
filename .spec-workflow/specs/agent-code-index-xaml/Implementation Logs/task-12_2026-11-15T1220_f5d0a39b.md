# Implementation Log: Task 12

**Summary:** Integrated XAML into IndexGenerator. New XamlIndexer reads the XAML of every project through IXamlFileSource (project folder from ProjectPath), builds the XamlWorld (assembly name from the compilation maps avares:// includes), detects the ViewLocator convention for each application document with its project's compilation, and resolves each project's files with a XamlResolver. XamlFileRecords go into ProjectIndex.XamlFiles and the XAML relationships are merged into the project's relationships. A malformed file is a LoadProblem error (HasErrors true) and the other files are still processed; an application file whose locator was registered but not recognized gets one finding. IndexGenerator takes an optional IXamlFileSource (null keeps the old behavior) and CliServices has an optional CreateXamlFileSource (the default reads the disk). 12 new tests, 465 pass.
