# Implementation Log: Task 15

**Summary:** Extended the reader and query service for XAML. IndexReader.XamlFile reads and schema-checks one XAML JSON file, and SymbolOf now returns null for XAML ids. New XamlQueries (XamlShow, NameOf with XamlIds.Describe) finds the XAML file of a view class through its CodeBehind edge and the file and entity of a XAML names entry. find returns XAML entries (View, Element, Resource, Style, Template) with the C# symbols using the same ranking. show returns ShowResult(Symbol?, Xaml?, Outgoing, Incoming): a view class includes its XAML file, a view file includes its class, and elements, resources, styles and templates show their edges (an element also those of its bindings and handlers). refs now also counts UsesViewModel, CodeBehind, BindsTo, ReferencesResource, UsesConverter, HandledBy, UsesType and Includes, so a view model property or command lists its XAML bindings, a handler method lists its XAML event, a converter or custom control class lists its XAML uses, a resource key lists its references, and a view model class lists its views with evidence and the inferred reason. XAML queries never read symbol files, an old XAML schema gives the regenerate message and a damaged file is reported. CliPrinter prints a minimal header for XAML-only results (full XAML printing is task 16). 22 new tests, 515+ pass.
