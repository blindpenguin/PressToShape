# Implementation Log: Task 2

**Summary:** Added command handler detection (R2). CommandHandlerLinker.FromGenerated gives a verified ExecutesMethod edge (reason [RelayCommand], located at the source method) from each property generated from a [RelayCommand] method. CommandAssignment plus a walker extension give a verified ExecutesMethod edge (reason 'new RelayCommand(method group)', with file and line of the assignment or initializer) for assignments, field initializers and property initializers whose value is new RelayCommand, RelayCommand<T>, AsyncRelayCommand or AsyncRelayCommand<T> with a method group that resolves to a method of the solution. Lambdas, parameters, locals, methods of other assemblies, other command types and assignments to locals record nothing. Note: C# only allows static methods in field and property initializers, so initializer forms are limited to static handlers. 12 new tests, 550 pass.
