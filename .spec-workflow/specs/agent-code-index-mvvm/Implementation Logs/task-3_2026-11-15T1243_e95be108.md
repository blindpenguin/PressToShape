# Implementation Log: Task 3

**Summary:** Added AvaloniaFactsExtractor (controls) and AvaloniaPropertyReader. Custom controls are solution classes whose base type derives from Avalonia.Controls.Control and that are not in the XAML class set, with base type, XML summary, file and line. Their static StyledProperty, AttachedProperty and DirectProperty fields give name (first constant string of the Register call, else the field name without 'Property'), property type, value type, default as written (the defaultValue argument), and CLR wrapper (instance property, or a static GetX for attached). Static RoutedEvent fields give name, argument type and the routing as written. Everything is sorted by name. Types are matched by full names and the registration call is read from the operation tree, so the tool needs no Avalonia reference. SourceTypes (shared type enumeration) was extracted from RelationshipBuilder, and XamlTestHost gained stub AvaloniaProperty, RoutedEvent and RoutingStrategies types plus AppProject (an app project that references the stubs as metadata). 11 new tests, 561 pass.
